## Unit Testing with Karma and Jasmine

### Script Configuration

Add or update the following script in `package.json`:

```js
"app": "sudo -v && ng run Test && ng s"
```

### Types of Unit Tests

Unit tests generally fall into two categories:

#### Isolated Tests

Test a single unit (e.g., a function or method) in isolation.

#### Integration Tests

Verify interactions between multiple units or functionalities.

##### Component Tests

- **`.ts` and `.html` → Shallow Integration Tests**  
  Test the interaction between the component's TypeScript logic and its template.

- **`.ts` → Isolated Tests**  
  Test the component's TypeScript logic independently from the template.

##### Deep Integration Tests

Verify communication between two or more components.

---

### Types of Mocks

| Type        | Description                                                                                                                           |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| **Dummies** | Objects that satisfy structural requirements but are not used during test execution.                                                  |
| **Stubs**   | Provide controlled behavior for dependencies.                                                                                         |
| **Spies**   | Monitor interactions (e.g., method calls, arguments, call count). Common Jasmine APIs: `jasmine.createSpy(...)`, `spyOn(..., "...")`. |

#### Spies Can Be Used To:

- Verify that a method was called with correct parameters.
- Check how many times a method was called.
- Simulate specific behavior under certain conditions.

---

### Comparison: `createSpyObj()` vs `createSpy()` vs `spyOn()`

| Method           | Purpose                                                                                                                                                  |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `createSpyObj()` | Creates a mock object with multiple spy methods. Can be used as spies or stubs when behavior is defined using `.and.returnValue()` or `.and.callFake()`. |
| `createSpy()`    | Creates a single spy function. Can also act as a stub when behavior is defined.                                                                          |
| `spyOn()`        | Creates a spy on an existing method of an object. Can be configured to simulate behavior.                                                                |

---

### `.and.returnValue()` vs `.and.callFake()`

| Method               | Behavior                                                                         |
| -------------------- | -------------------------------------------------------------------------------- |
| `.and.returnValue()` | Returns a fixed value regardless of input arguments.                             |
| `.and.callFake()`    | Replaces the implementation with a custom function that can use input arguments. |

**Example:**

```js
// returnValue
const spy1 = jasmine.createSpy("add").and.returnValue(5);
spy1(2, 3); // 5

// callFake
const spy2 = jasmine.createSpy("add").and.callFake((a, b) => a + b);
spy2(2, 3); // 5
```

### Test Suites and Test Cases

- **`describe("", () => {})`** → Groups related test cases.
- **`it("", () => {})`** → Defines an individual test case (follows **Arrange → Act → Assert**).
- **`xit("", () => {})`** → Disables a test temporarily (equivalent to `pending()`).

## Signals

### Types of Signals

- **`signal`** – Basic reactive state.

```ts
const count = signal(0);
```

- **`computed`** – Derived state.

```ts
const doubleCount: Signal<number> = computed(() => count() * 2);
```

- **`effect`** – Side effects.

```ts
effect(() => {
  console.log(`The current count is: ${count()}`);
});
```

- **`linkedSignal`** – Automatically updates when its source changes.

```ts
const shippingOptions = signal(["Ground", "Air", "Sea"]);
const selectedOption = linkedSignal(() => shippingOptions()[0]);
```

```ts

  path: "login",
```

### Navigation


### Reading Route State

```ts
const routes: Routes = [{ path: "product/:id", component: ProductComponent }];
productId = signal("");

private activatedRoute = inject(ActivatedRoute);

constructor() {
  this.activatedRoute.params.subscribe((params) => {
    this.productId.set(params["id"]);
  });
}
```
